# DashBoard-Crypto-and-Blockchain-Weekly-News

A weekly summary of cryptocurrency and blockchain news: Bitcoin, Ethereum, DeFi, altcoins and other chains, regulation and policy, stablecoins and payments, and other disruptive projects.

Each edition has an executive summary per section, with a "See more" button that opens a deeper analysis and its sources. It opens in dark mode (deep forest green) with a Light / Dark toggle at the top right.

## Files

- `index.html` is always the latest edition. Open it in any browser; it is a single self-contained page.
- `editions/YYYY-Www.html` keeps every past edition (ISO week number), for example `editions/2026-W43.html`.

## How it is updated

A new edition is produced every Monday at 08:00 Lisbon time. All the week's content lives in the `EDITION` object at the top of the page's script; the layout code stays the same from week to week.

Nothing on this page is investment advice.
